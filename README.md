# Email Phrase Fixer

A free desk tool from [Send This Instead](https://3368936654923.gumroad.com/l/pjgcqqj).

Paste a work email. The page flags stiff or dated phrases — *kindly revert*, *please do the needful*, *as per my last email*, and many others — and suggests wording you would actually send. Click **Replace**, then **Copy fixed email**.

Everything runs in your browser. Nothing is uploaded. There is no account and no API key.

## Use it

Open `index.html` in a browser, or visit the hosted page if one is listed in the repository description.

Try the example first if you want to see the tool on a typical stiff draft.

## What it is not

This is not a grammar course, not a chatbot, and not legal or HR advice. It only flags known phrase patterns.
